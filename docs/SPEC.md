# PG OS: Spec and Copilot Task Pack

How to use this file:
1. Save it in the repo as `docs/SPEC.md`.
2. Copy **Part 1 (Global context)** into `.github/copilot-instructions.md` so every Copilot session gets it.
3. Feed the tasks in **Part 4** to Copilot **one at a time, in order**. Finish, run, and commit each task before starting the next.
